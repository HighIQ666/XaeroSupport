# ExampleProject - BukkitOfUtils Example Project
This is an example project for using BukkitOfUtils in your projects.

This fork targets Paper 26.1.2 and provides server-side support for Xaero's Minimap and Xaero's World Map plugin channels. It is forked from [ProjectsForAll/XaeroSupport](https://github.com/ProjectsForAll/XaeroSupport).
